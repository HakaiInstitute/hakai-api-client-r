# hakaiApi: Authenticated HTTP Request Client for the 'Hakai' API

Initializes a class that obtains API credentials and provides a method
to use those credentials to make GET requests to the 'Hakai' API server.
Usage instructions are documented at
<https://hakaiinstitute.github.io/hakai-api/>.
